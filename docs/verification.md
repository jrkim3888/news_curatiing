## GitHub Actions 실행 설정

- Codex의 실행 프로세스가 환경 저장/복원 후 유지된다고 가정할 수 없어, 별도 상시 VM 없이 운영할 수 있는 Actions 예약 워크플로를 추가했습니다. Oracle cron 설정은 대안으로 보존합니다.
- 당시 `17 */6 * * *` 예약과 수동 실행, 중복 실행 방지, 기본 `GITHUB_TOKEN`의 저장소 쓰기 권한, 기본 1회 요약 한도, 요청 대기 캐시, 7일 복구 아티팩트를 설정했습니다.
- 예약 수집은 `COLLECTION_ENABLED=true`일 때만 동작합니다. 수동 실행의 기본값은 유료 LLM 호출 없이 링크만 수집합니다.
- actionlint **1.7.12**로 두 워크플로의 문법·표현식·Action 입력 검사 통과. 검사 도구는 공식 GitHub 릴리스의 SHA-256과 체크섬 파일을 확인한 뒤 사용했습니다.
- Python **23개 테스트**를 다시 실행해 모두 통과했습니다. 수집 래퍼의 로컬 bare Git 게시/복구 테스트를 포함합니다. 데이터 스키마 검증과 Bash 구문 검사도 통과했습니다. 이번 변경에서는 유료 OpenRouter 요청을 추가하지 않았습니다.
- GitHub `main`에 초기 코드를 게시했습니다. [Validate service 실행](https://github.com/jrkim3888/news_curatiing/actions/runs/38868660579)이 성공했고 Python 테스트·데이터 검증·npm 설치·타입 검사·정적 빌드 단계가 모두 통과했습니다.
- GitHub 호스팅 실행기에서 [Collect AI news 수동 실행](https://github.com/jrkim3888/news_curatiing/actions/runs/38868751624)을 `no_llm=true`로 실행해 성공했습니다. 변경 데이터만 담은 커밋 `9572293`이 `main`에 게시됐습니다. 데이터를 다시 받아 스키마를 검증했고 기사 141개, 기존 AI 요약 1개를 확인했습니다. 유료 요약 호출은 하지 않았습니다.
- 31,177바이트의 복구 아티팩트 생성과 업로드 단계 성공을 API로 확인했습니다. 이 Codex 환경에서는 GitHub 아티팩트 저장소 도메인의 네트워크 접근이 막혀 ZIP 다운로드 검증은 수행하지 못했습니다. 유료 요청이 없으므로 요청 대기 캐시 저장 단계는 예상대로 건너뛰었습니다.
- GitHub API에서 저장소 공개 상태와 코드 접근 권한을 확인했습니다. Actions 관리 설정·Secret/Variable 목록 API는 현재 연결 인증으로 HTTP 403이므로 설정 완료를 확인하지 못했습니다. 키와 변수는 사용자가 GitHub 설정 화면에서 등록해야 합니다.
- 공식 문서 소스에서 공개 저장소의 표준 실행기 무료 사용, 기본 브랜치 예약, 60일 비활동 시 중지, Pages Free 월 500회 빌드 한도를 확인했습니다.
- 캐시가 삭제되면 실패한 LLM 요청의 24시간 대기 상태는 유실될 수 있습니다. 성공한 기사/요약의 기준 데이터는 Git에 남습니다. Actions push 실패 결과는 아티팩트에서 수동 복구하며, VM의 다음 실행 자동 재전송과 구분합니다.

## 아직 실행하지 않은 검증

- **Oracle VM 배포와 실제 cron 시간 실행**: 서버 접속 정보 미제공. cron 래퍼를 격리한 로컬 Git 환경에서 검증했으며 Oracle의 OS·메모리·재부팅·인증은 배포 시 확인해야 함
- **GitHub Actions 유료 요약과 예약 시간 실행**: 수동 링크 수집과 커밋·push는 성공했지만, GitHub에 등록한 OpenRouter 키로의 요약과 실제 6시간 예약 실행은 아직 검증하지 않음. Secret/Variable 설정은 사용자 화면에서 필요
- **Pages 자동 배포**: 프로젝트 연결·실제 SITE_URL 설정·수집 커밋에 의한 자동 배포·외부 URL 검증은 배포 문서에 따라 수행해야 함
- **장기 운영**: 6시간 간격 여러 날의 누락률, 원문 구조 변경, 5,000개 이상 아카이브, 장기 비용은 아직 측정하지 않음

OpenRouter를 켜기 전에는 링크 모음으로 작동합니다. 현재는 모델이 연결되면 고정된 24시간 범위의 일일 브리핑을 생성합니다. 개별 기사 요약은 수동 옵션이며 모든 기사에 요약을 보장하지 않습니다. 기본 호출 수 상한과 OpenRouter 자체 키 credit limit을 함께 사용하세요.
