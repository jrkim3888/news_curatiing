# GeekNews 추천 수집 소스 검토 — 2026-11-02

대상은 [GeekNews 글](https://news.hada.io/topic?id=15184)과 댓글에서 사용자가 복사해 제공한 **27개 사이트**다. 글은 2024년 6월 게시됐으므로 추천 당시의 상태를 현재 수집 가능성으로 간주하지 않았다. GeekNews 페이지 자체는 이 환경에서 403을 반환했으며, 연결된 Hacker News의 전체 댓글 트리는 별도로 읽지 않았다.

실제 요청에는 기존 수집기의 HTTPS 호스트 제한·크기 제한을 사용했고, 로컬 파서로 날짜와 URL을 검사했다. 최근 3일 수치는 확인 시각의 표본이며 전체 과거 기사 수나 앞으로의 일일 수집량이 아니다. Robohub의 오래된 글을 새 기사처럼 날짜를 바꿔 넣지 않는다.

BleepingComputer의 robots에는 ClaudeBot 차단이 있어 기존 프로젝트의 보수적 정책을 따라 `summarize=false`, `fetch_body=false`로 설정했다. Techmeme는 링크 모음이므로 독립 취재나 AI 요약의 원문 근거로 사용하지 않는다. Robohub는 제공된 RSS 본문을 사용하고, 충분하지 않은 글은 원문 링크로 남는다.

Techmeme에서는 광고 이미지·매체 홈페이지가 아닌 **굵은 기사 제목의 링크**를 추출한다. 정상 원문 URL을 찾지 못하면 모음 페이지 링크를 유지한다. 같은 원문을 다른 출처에서도 수집하면 기존 URL 기반 중복 제거로 합친다. 임의로 외부 사이트의 본문을 추가 수집하지 않는다.

로봇 분야의 필터를 확인하면서 `artificial intelligence`, `deep learning`, `reinforcement learning`, `robot learning`처럼 약어 없이 쓰인 표현을 추가했다. 단순한 로봇 재료·하드웨어 기사 전체를 AI로 분류하지 않는다.

## 보류한 소스

[Interesting Engineering](https://interestingengineering.com/)의 홈페이지는 접근할 수 있었지만 공식 RSS 자동 발견이나 피드 링크를 확인하지 못했다. 목록 어댑터, 발행 시각과 유료 글 구분을 별도로 검증하기 전에는 운영 수집에 추가하지 않는다.

`engineeringblogs.xyz`는 기존 연구 목록의 모호한 “Engineering Blogs” 항목에 연결했다. 댓글에서만 등장한 `csr.netking.xyz`도 후보로 기록했다. 네트워크 접근이 가능한 운영 환경에서 검증을 이어갈 수 있도록 전체 후보 URL과 오류·검증 수치는 [JSON 기록](2026-11-02-hada-15184.json)에 남겼다.

## 반영과 검증

- 운영 설정: `config/sources.json`. 홈페이지의 출처 목록은 공개 `data/sources.json`도 함께 갱신한다.
- 기존 후보 연구 목록: `docs/source-research.json`. 활성 상태는 운영 설정을 반영하고 이번 검토 기록을 연결한다.
- 정상 원문 추출, 잘못된 원문 URL의 대체 링크, 후원 작성자 필터, AI 표현과 일반 로봇 하드웨어 구분을 테스트한다.
- 이번 소스 검토에는 유료 LLM 요청을 사용하지 않는다. 새로운 소스에도 기존 기사별·브리핑 요청 한도를 적용한다.
